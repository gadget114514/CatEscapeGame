[English README (CatEscapeJs/README.md)](CatEscapeJs/README.md)

A hex-board game that includes both classic "Trap the Cat" (Chat Noir) and its reverse, where you play the cat and escape.  
Built with Babylon.js + Vite, runs on GitHub Pages and as an Electron desktop app.

## Repository layout

- `CatEscapeJs/` — main application (source, tests, build, Electron)
- `.github/workflows/pages.yml` — manual GitHub Pages deploy
- `LICENSE`
